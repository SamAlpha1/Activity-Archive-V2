# Contributing

Thank you for considering a contribution.

- Open or review an issue before substantial changes.
- Keep changes focused and avoid unrelated refactors.
- Never commit credentials, private keys, tokens, seed phrases, or production secrets.
- Describe the problem, solution, and related issue in each pull request.
- Add or update tests for behavior changes and update relevant documentation.
- Run the test, lint, and build commands documented in this repository's README and project configuration.
- Report the exact validation commands and results; do not claim checks passed unless they were run.
- All changes are subject to maintainer review. Security-sensitive changes may require additional review.
